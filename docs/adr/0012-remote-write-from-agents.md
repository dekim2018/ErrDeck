# ADR 0012. 다른 서버의 지표는 에이전트가 밀어 보낸다

- 상태: 확정
- 결정일: 2026-11-23
- 관련 문서: [11-OBSERVABILITY.md](../11-OBSERVABILITY.md) (13.3)

## 고른 것

감시 대상이 다른 서버에 있으면 그 서버에 프로메테우스를 에이전트 모드로 띄워 로컬에서 수집하고 중앙으로 원격 쓰기를 한다. 같은 도커 네트워크에 있으면 중앙에서 직접 수집한다.

## 버린 대안

중앙에서 인터넷으로 Actuator를 직접 수집

## 이유

- 감시 대상 서버는 나가는 연결만 쓴다. Actuator 엔드포인트를 인터넷에 열지 않는다.
- 팬파라이브 서버는 평소 꺼져 있다. 켜지면 알아서 다시 보내고, 꺼진 동안 수집 실패 경보가 울리지 않는다.

## 감수하는 것

- 감시 대상 서버에 컨테이너가 하나 늘어난다.
- 중앙의 원격 쓰기 경로를 인증과 함께 외부에 열어야 한다.

## 측정할 값

에이전트의 메모리 사용량, 원격 쓰기 지연

## 다시 검토할 조건

부하 실험과 장애 실험 결과가 이 결정의 전제와 다르게 나오면 이 문서를 고치고 상태를 "대체됨"으로 바꾼다.

# ADR 0010. 모든 대기 공간에 길이를 두어 역압을 SDK까지 전한다

- 상태: 확정
- 결정일: 2026-11-23
- 관련 문서: [12-RESOURCES.md](../12-RESOURCES.md) (14.5)

## 고른 것

worker 안의 넘겨주기 큐와 쓰기 큐, Redis 스트림, SDK의 전송 큐에 전부 길이 상한을 둔다. 뒤가 막히면 앞이 차례로 멈추고, 마지막에는 ingest가 503을 응답해 SDK가 전송을 쉰다.

## 버린 대안

길이 제한 없는 큐. 막히면 오래된 것부터 조용히 버리기

## 이유

- 길이 제한이 없으면 뒤 단계가 느려질 때 메모리가 끝없이 늘어난다.
- ClickHouse가 10분 동안 멈춰도 어느 프로세스의 메모리도 계속 늘지 않는다.
- 거절을 분명하게 응답하면 SDK가 버린 건수를 셀 수 있다(0004).

## 감수하는 것

- 뒤가 막힌 동안의 원본은 잃는다. 건수는 남는다.
- 큐 길이를 실측으로 맞춰야 한다.

## 측정할 값

ClickHouse를 멈춘 실험에서 프로세스별 메모리, 거절 응답 수, 재개 후 복구 시간

## 다시 검토할 조건

부하 실험과 장애 실험 결과가 이 결정의 전제와 다르게 나오면 이 문서를 고치고 상태를 "대체됨"으로 바꾼다.

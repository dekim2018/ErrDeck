# ADR 0007. 소스맵 해석기를 Java로 직접 구현하고 배열로 보관한다

- 상태: 확정
- 결정일: 2026-11-23
- 관련 문서: [05-SOURCEMAP.md](../05-SOURCEMAP.md) (7.3, 7.4)

## 고른 것

소스맵의 mappings를 Java로 해석해 int 배열에 담고, 줄 안에서 이진 탐색으로 찾는다. 해석 결과는 바이트 합계로 크기를 제한한 캐시에 두고, 같은 소스맵의 동시 해석은 한 번만 일어나게 한다.

## 버린 대안

브라우저에서 복원. Node 프로세스를 옆에 띄워 기존 라이브러리 사용. 조회할 때만 복원. 구간을 객체 목록으로 보관

## 이유

- 지문 계산에 복원 결과가 필요하므로 처리 시점에 서버에서 해야 한다.
- 소스맵을 공개 경로에 두지 않아도 된다.
- 구간마다 객체를 만들면 수십만 개의 객체 헤더가 힙을 차지한다.
- 프론트 배포 직후 같은 소스맵을 찾는 이벤트가 한꺼번에 온다. 스레드마다 해석하면 CPU와 힙이 동시에 바닥난다.

## 감수하는 것

- 해석기의 정확성을 직접 책임져야 한다. 기존 라이브러리와의 대조 테스트로 확인한다.
- 색인 소스맵 같은 드문 형식은 처음에는 지원하지 않는다.

## 측정할 값

소스맵 크기별 해석 시간, 해석된 배열의 힙 사용량, 캐시 적중률, 복원 실패율

## 다시 검토할 조건

부하 실험과 장애 실험 결과가 이 결정의 전제와 다르게 나오면 이 문서를 고치고 상태를 "대체됨"으로 바꾼다.

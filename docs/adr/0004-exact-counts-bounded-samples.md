# ADR 0004. 건수는 정확하게, 원본은 제한해서 저장한다

- 상태: 확정
- 결정일: 2026-11-23
- 관련 문서: [03-INGEST.md](../03-INGEST.md), [08-DATA-MODEL.md](../08-DATA-MODEL.md) (5.1, 5.6, 10.3)

## 고른 것

버리는 곳마다 건수를 남긴다. SDK는 접은 횟수와 버린 건수를 보내고, worker는 받은 이벤트 전부를 집계 테이블에 더하되 원본은 이슈별 분당 상한까지만 저장한다.

## 버린 대안

받은 이벤트 원본을 전부 저장. 폭주 때 초과분을 조용히 버리기

## 이유

- 같은 예외 1만 건의 스택트레이스를 전부 저장할 이유는 없지만, 1만 번 발생했다는 사실은 알아야 한다.
- 횟수, 그래프, 알림의 빈도 판정이 집계 테이블만 읽으므로 원본을 줄여도 숫자가 변하지 않는다.
- 저장량이 발생 건수가 아니라 이슈 수에 비례한다.

## 감수하는 것

- SDK가 건수를 보내기 전에 감시 대상 프로세스가 죽으면 그 건수는 사라진다.
- 상한을 넘긴 구간의 개별 이벤트는 나중에 볼 수 없다.

## 측정할 값

폭주 실험에서 보낸 건수와 집계 건수의 차이

## 다시 검토할 조건

부하 실험과 장애 실험 결과가 이 결정의 전제와 다르게 나오면 이 문서를 고치고 상태를 "대체됨"으로 바꾼다.

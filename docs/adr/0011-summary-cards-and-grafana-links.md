# ADR 0011. 지표는 요약 카드만 화면에 올리고 상세는 그라파나로 잇는다

- 상태: 확정
- 결정일: 2026-11-23
- 관련 문서: [10-CONSOLE.md](../10-CONSOLE.md) (12.1)

## 고른 것

콘솔은 에러, 성능, 업타임을 직접 그리고, 서버 지표는 서비스마다 숫자 6개짜리 요약 카드로만 보여 준다. 상세 시계열은 같은 서비스와 같은 시간대를 가리키는 그라파나 링크로 넘긴다.

## 버린 대안

지표 차트를 콘솔에 직접 구현. 지표는 그라파나 링크만 제공

## 이유

- 시계열 차트의 확대, 기간 비교, 변수 전환은 그라파나가 이미 잘한다. 다시 만드는 것은 이 프로젝트의 차별점이 아니다.
- 링크만으로는 서비스가 정상인지 판단하려고 매번 화면을 옮겨야 한다.
- 이슈의 최초 발생 시각에 맞춘 링크로 에러와 자원 상태를 시간으로 이을 수 있다.

## 감수하는 것

- 콘솔과 그라파나의 로그인이 따로다.
- 요약 카드는 프로메테우스가 내려가면 비어 보인다.

## 측정할 값

요약 카드 조회 시간, api에서 프로메테우스로 가는 질의 수

## 다시 검토할 조건

부하 실험과 장애 실험 결과가 이 결정의 전제와 다르게 나오면 이 문서를 고치고 상태를 "대체됨"으로 바꾼다.
